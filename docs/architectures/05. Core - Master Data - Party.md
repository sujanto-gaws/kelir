# Core: Master Data - Party

**Status:** Adopted · **Last updated:** 2026-08-12

Below is a **complete JSON Schema** for an **OFBiz-style Party structure**.

This schema models a **Party aggregate** that can represent:

```text
Tenant
Employee
Customer
Supplier
Contact Person
Party Group / Organization
```

It includes:

```text
Party
Person
Party Group
Party Roles
Party Identifications
Party Statuses
Party Relationships
Party Classifications
Contact Mechanisms
Party Notes
Tenant Profile
Employee Profile
Customer Profile
Supplier Profile
Contact Profile
```
