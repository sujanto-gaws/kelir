## Root Causes

**A reading placed on a day waits for a person on that day.** Plan 20 gave record 23 two controls. One was a merge gate, *no row that changes the workflow module merges before it lands*, and it held. The other was a date, *the sprint's first day*, and nothing enforced it. **This is [retrospective 14](14.%20Sprint%2016%20Retrospective.md)'s root cause again**: a control holds when it blocks something the project wants, and fails when it asks for diligence at a time. Record 24's range is closed at `a9f1cdf`, so its reading can start the day this close merges, before Sprint 25 has a plan.

**The merge control holds by conduct, not by a setting.** Sprint 23's broke by conduct three times, and Sprint 24's held by conduct on every merge. The difference is not in the repository: the check, the convention and the git workflow's sentence are the same in both sprints. **Retrospective 21's root cause stands**: a control built in the repository and switched on outside it is not on until the switch is.

**A state note rides in the next change, so a merge is recorded only when another change carries a note.** When three rows merged within 10 h 26 min on 2026-10-21, none of them carried one. The last row had no next change. **And a figure measured before the squash was carried as final.** Plan 20's notes said *the squash commit's count replaces this one at the merge*, and for #732 and #744 nothing replaced it. The pair's *final* figure was set from one of them.

**Every gate files what it finds beside the row, and nothing sizes what it files.** That is the right call for the row: its criteria stay its own. But plan 20 §5 placed each new issue in hardening by default, and gave a size to none but #728 and #739, the two built in the sprint. **Hardening is where the unsized work collects**, and its own work is unsized too.

**A follow-up written in a PR body has no reader after the merge.** Retrospective 21's third action reads the tracker, and a body is not the tracker. A follow-up that is not filed is in no state note and no plan.
