## Scope Changes This Sprint

- **`0003_audit.sql` arrives earlier than the schema document maps it.** `audit_events` is documented as part of the Phase 6 activity migration, but FR-AUTH-008 is Phase 2 scope and sqlx applies migrations in version order — a later phase cannot insert a lower-numbered file. The migration records why at the top; the Database Schema document needs its mapping table updated to match.
- **CI now runs a PostgreSQL service.** The `query!` macros verify SQL against a real schema at compile time, so the build needs a database, not only the tests. This also satisfies coding standard §2.9's "run against a real PostgreSQL" for when repository tests land.
- **Dependencies added:** `argon2`, `jsonwebtoken`, `sha2`, `rand`, `chrono`.
- No FR was added, removed or re-scoped.
