# Sprint 2 Status — 2026-08-12

**Status:** Final · **Last updated:** 2026-08-12

**Phase:** 1 Foundation (SDD §14) · **Sprint goal:** the frontend half of the running Kelir skeleton — app shell, envelope-aware API client, login page, and the UI baseline.

## Summary

**Goal partially met: four of five issues done, #12 (staging) not started.** The frontend now has a working shell, a typed API client that unwraps the backend envelope, a login page, and the Tailwind v4 + shadcn-vue baseline. All ten gates pass across both stacks (backend 35 tests, frontend 23).

**Staging is not blocked by engineering — no host has been named for it.** That decision was raised as a Sprint 1 entry criterion and is still open, so #12 stays open and Phase 1 cannot tag `v0.1.0` yet.

The sprint's significant finding is that **the frontend could not talk to the backend at all**: no CORS layer existed, so the browser refused every response and the preflight returned 405. Unit tests could never have caught it — both sides were individually correct. It was found by running the pair together.
