# Sprint 10 Status — 2026-08-28

**Status:** Final · **Last updated:** 2026-08-28

**Phase:** 5 Workflow Engine (SDD §14) · **Sprint goal:** a submitted document enters an approval it cannot leave by accident — a definition becomes a running instance, the instance generates the task, someone approves or rejects it, and the document's status follows from that rather than beside it.

## Summary

**The sprint goal is met and every construction item is built. No item is `Done`.** All seven items are on the branch with the full suite green, and **the exit demo was run** — in a real browser, against release images built from this tree, with two people in it. But [sprint plan](../planning/01.%20Sprint%20Plan.md) §2 makes an item whose author is also its only verifier `In progress`, and **this sprint had no second reader** — every construction commit, every test and all six verification findings are one author's. Every row below therefore reads `author-verified`, and [record 07](../verifications/07.%20Sprint%2010%20Surface%20Verification.md) §1 says so before it says anything else. It is the second sprint running.

**The engine is one function, and that is checkable rather than claimed.** `engine::fire` is the only path that moves a process; the submit and the decision both call it, and Sprint 11's return and delegate will call the same one. The construction plan said *an engine is the shape a codebase most easily grows two of* before a line was written, and §2 and §7.1 were arranged so that a second one had nowhere to appear.

**Three of the sprint's invariants are database constraints rather than habits.** An instance cannot be in a state its definition does not declare (`fk_workflow_instances_current_state`); a document cannot have two live processes (`uq_workflow_instances_live_document`); a process cannot have two open tasks (`uq_workflow_tasks_open_per_instance`, which is "sequential approval only" written down so that FR-WF-016 has something to argue with). Each was a sentence in an acceptance criterion and each is now a fact a reader can check without reading the service.

**And the connection rule is a type signature.** Every function on the engine path takes `&mut PgTransaction` and none takes `AppState`, so **D-35**'s two-connection deadlock — written twice in Sprint 9 — cannot be written here without changing a signature. That is the Sprint 9 retrospective's first action applied *before* there was a violation rather than after one.

**Two decisions were taken during construction and recorded in [Product Backlog](../planning/02.%20Product%20Backlog.md) §6.1.** **D-36** refuses a manual status change on a document a workflow is deciding, which withdraws something the document surface shipped one sprint earlier and is the price of the projection being one-way. **D-37** refuses two of JWSS's six `assigneeType` values at save, and records the narrowing in the standard as [JWSS §5.3](../../docs/schema/JSON%20Workflow%20Schema.md) rather than only in code.

**The predicate-coverage ratio is 68%** — 23 of 34 mutations red, and the highest this project has recorded: 65%, 37%, 22%, 48%, **68%**. It did not get there by itself. The campaign's first run found **seven predicates nothing held**, all seven were closed with tests inside the sprint rather than filed, and **six of those seven are red in the run above** — so the closing was real rather than a rewording.

**Eleven predicates survived, and eight of them are hidden behind a layer that refuses first.** That is [record 07](../verifications/07.%20Sprint%2010%20Surface%20Verification.md)'s F7, and it is the one finding this sprint does not close: the behaviour behind each is tested through the layer in front of it, and reaching past that layer is a repository-level test per predicate. One green is *expected* — the sequential-approval index has no code path that can attempt a second open task, which is the point of it.

**The measurement took four attempts.** Three died to linker contention with a second worker in this working tree — nothing to do with any mutation. The run that produced the number has a build directory of its own, which is the [retrospective](../retrospectives/08.%20Sprint%2010%20Retrospective.md)'s action discharged in the act of needing it.
