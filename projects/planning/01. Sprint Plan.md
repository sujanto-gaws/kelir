# Kelir Sprint Plan

**Status:** Living · **Last updated:** 2026-08-24

This plan maps the Development Roadmap (System Design Document §14, Phases 1–9) onto a sprint cadence. It is **scope-sequenced, not date-committed**: sprint contents are the commitment, calendar dates shift with measured velocity. Re-baseline after Sprint 2 and at every phase boundary.

Related documents: requirements and FR IDs in [srs.md](../../docs/requirements/srs.md); system design in the [SDD](../../docs/design/01.%20System%20Design%20Document.md); engineering rules in [docs/standards/](../../docs/standards/); release mechanics in [04. Release Process.md](../../docs/standards/04.%20Release%20Process.md). The FR-level scope inventory behind this sequence is the [Product Backlog](02.%20Product%20Backlog.md) — it maps every requirement to an epic and a sprint, and records the open scope decisions this plan depends on.

## 2. Cadence and Definition of Done

- Ceremonies: planning (first day), demo + review (last day), retro (last day, 30 min). Backlog refinement mid-sprint.
- A backlog item is **Done** when: code merged to `main` per the [git workflow](../../docs/standards/05.%20Git%20Workflow.md); tests per [coding standard](../../docs/standards/01.%20Coding%20Standard.md) §2.9/§3.5 pass in CI, and any security-control or contract test among them has been seen to fail against a reintroduced defect (§2.9); API changes reflected in OpenAPI; audit/permission checks in place; demoable from the Docker Compose stack built from release images.
- **The environment clause names Docker Compose because that is the environment this project has** (decision **D-9**, 2026-08-21). It read "demoable from a staging deploy" and was waived four sprints running, twice with an expiry that was extended rather than met — `kelir-staging-01` was never provisioned and no infrastructure is available to host it. The replacement keeps the property the clause was protecting: what is demonstrated is built the way a release is built, from release images, not run out of a working tree. It is also meetable, which the previous wording was not, so a waiver stops being the normal case. Staging is unscheduled rather than abandoned — [`deploy/staging/`](../../deploy/staging/) keeps its definition and says plainly that nothing runs it.
- **An item whose author is also its only verifier is `In progress`, not Done** ([Sprint 5 retrospective](../retrospectives/03.%20Sprint%205%20Retrospective.md), 2026-08-21). Sprint 5 met the previous wording — every Done row cited evidence — while for two of its seven items the evidence was twenty mutation runs designed by the agent that had written the code. Mutation runs are strong evidence of what the tests catch and no evidence of what nobody thought to test. The independent pass fired in Sprint 4 only because that sprint's work was under suspicion; naming it here is what stops it from depending on somebody already being worried.
- Every sprint ends demoable; every **phase** ends with a tagged release (§4).
