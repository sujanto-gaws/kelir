| `0041_activity_read_dropped.sql` | Deletes the `activity:read` grants, then the permission row | **Compatible, and this is the release it waited for.** `v0.5.0`'s binary called `caller.require("activity:read")`; `v0.6.0`'s does not, so the N−1 for this migration reads the row in no statement. Deprecate in N, remove in N+1 — release process §6, followed to the letter |
| `0042_rad_action_scoped_to_a_list.sql` | Adds nullable `rad_actions.list_id`, a composite FK, a `CHECK`, a partial index, and a unique constraint on `rad_lists (id, tenant_id)` | **Additive and nullable.** `v0.6.0` never selects the column; the null preserves the old behaviour, so no data migration had to guess a list for an existing tenant-wide action |
