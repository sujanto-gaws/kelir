**Why it passed, migration by migration.** `0040` inserts permission rows `v0.6.0` reads as catalogue and checks in no route. `0041` deletes a row `v0.6.0` checks in no statement ([record 15](../verifications/15.%20Sprint%2016%20Independent%20Pass.md) §4). **`0042` is the only one that reaches a table `v0.6.0` knows**: `git grep rad_actions v0.6.0 -- kelir-backend/src` returns **nothing**, so the new column, `CHECK` and foreign key on `rad_actions` are invisible to it; and `uq_rad_lists_id_tenant_id` is unique over a superset of `rad_lists`' primary key, so it can refuse nothing the key accepts — which the `201` above shows rather than argues.

### §6 step 3 — the compiled check, run and controlled

**`v0.6.0`'s source, every target including its tests, type-checks against the `0042` database**: `cargo check --all-targets` with `SQLX_OFFLINE=false`, exit 0. [Record 06](06.%20Release%20v0.6.0.md) did not run this step; [record 05](05.%20Release%20v0.5.0.md) did.

**A green compile proves nothing unless the macros reached the schema** rather than `v0.6.0`'s own `.sqlx` cache, so it was controlled. With the crate cleaned, the same source against an **empty** database went **red — exit 101, 580 error lines, `relation "activity_events" does not exist`** — and against the `0042` database straight after, **green, exit 0**. Every statement `v0.6.0` holds type-checks against the schema this release leaves behind.

```
error: the frontend reports , expected 0.6.0 — the wrong image is serving
```

while `kelir-backend:0.6.0` and `kelir-frontend:0.6.0` were running and `/health/ready` answered 200. **[#367](https://github.com/sujanto-gaws/kelir/pull/367) added the `/version.json` assertion on 2026-09-07, and `kelir-frontend:0.6.0` predates it**, so the path falls through to Caddy's single-page fallback — `200 text/html`, `index.html` — and the check reads an empty version and calls the right image the wrong one. **`v0.6.0` is the only rollback target `v0.7.0` has**, so the first operator to follow the script's own instruction after this release gets a red rollback that is not one.
